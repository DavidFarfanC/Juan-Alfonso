# Portafolio · Juan García Arquitecto

Sitio web minimalista tipo Apple para presentar el trabajo del arquitecto Juan García. Construido con React + Vite y animaciones suaves basadas en Intersection Observer.

## Requisitos

- Node.js 18 o superior

## Comandos principales

```bash
# Instalar dependencias
npm install

# Ejecutar el entorno de desarrollo
npm run dev

# Generar la versión de producción
npm run build

# Previsualizar la build
npm run preview
```

## Notas de diseño

- Paleta neutra en tonos arena, negro profundo y acentos dorados.
- Composición editorial con tipografía Inter e interletraje amplio.
- Animaciones on-scroll sutiles para secciones, tarjetas y elementos clave.
- Layout totalmente responsivo con foco en experiencias premium (hero, proyectos destacados, manifiesto del estudio, testimonios y contacto).
